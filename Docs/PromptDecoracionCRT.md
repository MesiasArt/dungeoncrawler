Generate one rectangular screen viewed perfectly head-on, no perspective, no monitor housing, no scene. Dark navy almost-black background, pixel-art 1980s arcade sci-fi diagnostics, cyan code rows, magenta corrupted data blocks, a simple cyan wireframe memory-chip diagram on the left and a few magenta warning bars on the right. Strong large pixel shapes, limited blue/cyan/magenta/violet palette, black pixel outlines, crisp nearest-neighbor appearance, subtle drawn scan lines, no realistic lighting, no photographic reflections. Fill the entire canvas with the screen artwork. Exact short text at top: 'MEMORY CHECK'. Exact short text near bottom: 'SIGNAL LOST'. Other code rows should be abstract glyph bars rather than legible prose. This texture will be placed on a 3D terminal and CRT monitor in a neon grid dungeon, so keep it legible from a few metres away and avoid tiny noisy details. Landscape 4:3 composition.
